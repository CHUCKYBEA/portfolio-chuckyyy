# CHUCKY BEA — Digital Identity

A responsive, dark crimson cyber-tech personal portfolio built with React + Vite.

## Features
- Responsive layout for mobile, tablet and desktop
- Dark red cyber / terminal-inspired visual system
- Animated hero identity panel, ticker and terminal typing effect
- About, skills, project showcase and contact sections
- Reduced-motion accessibility support
- Vercel-ready static build

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Vercel should detect **Vite** automatically.
4. Build command: `npm run build`
5. Output directory: `dist`
6. Click **Deploy**.

## Personalize before publishing
Update `src/App.jsx`:
- Replace `hello@chuckybea.dev` with your real email.
- Replace the GitHub and Telegram links with your real profile URLs.
- Replace the sample project concepts with real projects and repository links.
- Update the skill levels to match your actual experience.

The project cards are explicitly labelled as concepts so they do not imply completed client work.
